# DataPolish · 数据清洗工坊

一个轻量级的 Streamlit Web 应用：上传 CSV / Excel，交互式处理缺失值，并用 Plotly 在 4 个标签页中完成从单变量分布到多维关系分析的可视化探索。

## 功能

- **数据上传与概览**
  - 支持 `.csv`、`.xlsx`、`.xls`；Excel 默认读取第一个工作表。
  - 自动展示总行数、总列数、缺失值总数、完整行数、字段类型统计。
  - 原始数据前 5 行预览；可展开查看全部字段的缺失率与唯一值数量。
- **交互式缺失值清洗**
  - 按字段显示缺失数量和缺失比例。
  - 每个字段可独立选择：保持不变、删除缺失行、均值填充、中位数填充、众数填充、自定义值填充。
  - 数值型字段才提供均值、中位数选项；类型不匹配会被校验并提示。
  - 点击“应用清洗”后更新预览，异常会以 `st.error` / `st.warning` 提示。
  - 清洗结果保存在 `st.session_state`，支持下载 UTF-8 BOM 编码的 CSV。
- **单变量分布（原有能力）**
  - 数值字段：直方图、箱线图或两者组合，自动显示均值、中位数、标准差、缺失数和离群点。
  - 分类 / 文本字段：频数柱状图或环形饼图；长尾类别自动合并，缺失值单独标注。
  - 全部字段默认自动展示，可按字段筛选；多列网格布局，Plotly 支持缩放和悬停。
- **高级多维可视化（v1.1 新增）**
  - **散点图**：自由选择 X/Y 数值字段，支持分类颜色分组、点云分布、线性趋势线，并显示 Pearson r。
  - **KDE 密度图**：用纯 NumPy 高斯核与 Silverman 经验带宽平滑呈现单个数值字段的概率密度，无需额外科学计算依赖。
  - **折线图**：以数据索引或任意数值字段为 X 轴，查看数值指标的序列趋势，支持按 X 排序和显示数据点。
  - **堆叠柱状图**：组合两个分类型字段，支持计数和行内百分比两种呈现方式，长尾类别自动合并。
  - **分组箱线图 / 小提琴图**：以分类型字段对比数值分布，支持第二分类字段进行二重分组；小提琴图结合箱线统计与核密度轮廓。
  - **相关性热力图**：自动对全部有效数值字段计算 Pearson 或 Spearman 相关系数矩阵，支持格内数值标注，并列出绝对值最大的相关字段对。
  - 可视化页面使用 4 个标签页组织：`单变量分布`、`双变量关系`、`分组对比`、`相关性矩阵`。
- **容错与性能**
  - CSV 自动尝试 `utf-8-sig` / `utf-8` / `gb18030` / `big5` 编码，并自动识别分隔符。
  - 非法自定义填充值、全空字段、文件解析失败、字段类型不满足绘图条件等场景均有友好提示。
  - 单变量数值图最多抽样 20,000 个点；散点图与 KDE 最多各使用 5,000 个点；分组分布图最多抽样 20,000 行，交互更流畅。
  - 长尾分类字段可合并为“其他”，避免图例和坐标轴过长。

## 快速开始

要求 Python 3.9+。

```bash
cd data_cleaner_app
python -m pip install -r requirements.txt
streamlit run app.py
```

浏览器通常会自动打开 `http://localhost:8501`。左侧上传自己的文件，或点击首页的「加载示例数据」体验完整流程。

> `.xls` 读取依赖 `xlrd`（已包含在 `requirements.txt` 中）；`.xlsx` 依赖 `openpyxl`。

## 核心函数

| 函数 | 职责 |
| --- | --- |
| `load_data(file_name, payload)` | 读取 CSV / Excel，处理编码和异常，结果进入缓存 |
| `build_column_profile(df)` | 字段类型、缺失、唯一值等体检信息 |
| `clean_data(df, configs)` | 执行按列清洗策略，返回数据、报告和警告 |
| `build_scatter_figure(...)` | 散点图、分类着色、线性趋势与相关系数 |
| `build_density_figure(...)` | 高斯核密度估计曲线 |
| `build_line_figure(...)` | 索引 / 数值 X 轴折线趋势 |
| `build_stacked_bar_figure(...)` | 双分类字段的堆叠构成 |
| `build_group_box_figure(...)` / `build_group_violin_figure(...)` | 分组箱线图与小提琴图 |
| `build_correlation_figure(...)` | Pearson / Spearman 相关性热力图 |
| `render_visualizations(raw_df, clean_df, token)` | 数据源切换与 4 个分析标签页入口 |
| `render_overview()` / `render_cleaning()` | 数据概览和缺失值清洗页面 |

## 清洗语义说明

- **删除缺失行**：所有设置为该策略的字段会联合处理。一行只要在任意一个选中字段上缺失，就会被删除。
- **均值 / 中位数**：只对数值型字段生效；全空数值列会跳过并提示。
- **众数**：对数值、文本和布尔字段均可用；如果有并列众数，取排序后的第一个。
- **自定义值**：按照目标列类型校验。整数列拒绝 `3.5`，数值列拒绝 `NaN` / `inf`，日期列要求可解析的日期。
- **可重复应用**：每次应用都从原始 DataFrame 重新计算，不会在旧清洗结果上叠加，避免反复试验造成误差累积。

## 分析说明

- 相关性热力图默认使用成对完整观测；相关系数只描述关联强度，不代表因果关系。
- 分组箱线图与小提琴图会在需要时对长尾类别做合并，忽略所选字段缺失的记录，并在图表上方显示有效记录数。
- KDE 仅支持单个数值字段，避免不同量纲的字段放在同一坐标轴上造成误读。
- 所有高级图表使用当前选择的“清洗后数据”或“原始数据”，字段选择保存在 `st.session_state`。

## 数据与隐私

文件只在运行 Streamlit 的本地 Python 进程中解析，并保存在当前浏览器会话的 `st.session_state` 中；应用不会把数据上传到第三方服务。关闭会话后，会话数据随之释放。
